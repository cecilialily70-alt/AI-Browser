# 滑块缺口拖拽

## 何时用

页面出现「请按住滑块，缓慢拖动…」或缺口拼图阴影时：

本轮唯一动作：`{"solve_captcha": {}}`

（别名 `solve_slider_captcha` 同路径；失败后勿换别名顶次数。）

> 验收口径：页内裁决文案、协议成功体、或手柄停在缺口位置才算通过；
> 「手柄只是离开起点」不再当作通过。

## 工具行为

1. 类型门禁 `slider_gap_drag`
2. 定位底图 / 手柄 / 轨道
3. 像素精定位（**相对背景亮度** + 灰缺口连续性 + **局部对比度**抗涟漪 + 彩色惩罚 + 拼图宽度滑窗）；低置信/异常则视觉交叉校验并融合（视觉优先静默拉图）
4. 拟人拖拽（缓入缓出 + 微抖 + 轻微超冲回落）；重试只重定位缺口（不做固定像素微调）；监听校验响应
5. 验收：页内裁决文案 / 协议成功体 / 手柄停在缺口位置才算通过；用完即毁临时图；满 3 次失败再 HITL

## 禁止

- 刷新换图 / 同轮夹带 navigate
- 用 GIF 动图工具死磕滑块题
- 瞬移改 style.left 代替真实拖拽
