==================================================
  天枢台 (TianshuTai) - 便携版使用说明
==================================================

一、启动
  1. 双击 Start-TianshuTai.bat（或直接运行 TianshuTai.exe）
  2. 首次运行会自动检测依赖环境

二、运行环境要求
  - Windows 10/11 x64
  - WebView2 运行时（缺少时脚本会提示安装）
  - Node.js（Sidecar 依赖，脚本会检测并提示）

三、内核说明
  本便携包已内置 Chromium 内核于 Browse\ 目录：
    - chromium-146.*      免费核（AI / Agent / 填表，免费档并发 1）
    - chromium-151.*-pro  Pro 指纹核（免费 Key 下仅指纹浏览）
  应用启动环境时会【优先使用】Browse\ 下的本地内核，无需联网下载。
  如需更多内核，可将 chromium-* 目录放入本目录下 Browse\（或 内核\），
  然后在「设置 → 指纹浏览器内核 → 本地内核检测」中重新检测并设为默认。

四、License
  在「设置 → 浏览器内核密钥」粘贴 CloakBrowser 邮件中的 cb_ 开头密钥，
  保存并验证后即可下载 / 使用 Pro 内核（151）。

五、常见问题
  - 打不开浏览器：确认 WebView2 与 Node.js 已安装，且未单独移动 exe
    （exe 必须与 sidecar\、Browse\ 同级）。
  - 提示内核下载 404：在设置中选择「本地内核」或确认 Browse\ 内有内核。
