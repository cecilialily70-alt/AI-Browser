# 聊天图库（chat_media）

聊天模式发图只从**当前生效的图库目录**取文件。默认是本目录（随软件打包）；也可以在「设置 → 聊天 → 发图图库」里改成本机任意文件夹。

文件名和文件夹名必须用**中文或英文**（可加数字、`_`、`-`），方便按对方的话匹配。

## 怎么放图

- **文件夹 = 一类货**（型号 / SKU），例如 `iPhone_18_Pro_Max` 或 `深蓝ProMax`
- **文件 = 颜色或角度**，例如 `深蓝_正面.jpg`、`desert_gold_front.png`
- 也允许把同类型的图都放进同一个文件夹，不分子文件名细节
- 支持后缀：`jpg` / `jpeg` / `png` / `webp` / `gif`

对方说「Pro Max 深蓝」时，会优先匹配文件夹名里的 Pro Max，再匹配文件名里的深蓝。匹配不到就不会乱发一张。

自定义目录写了却不存在或没有图片时，不会偷偷改回软件自带图库——要图时只会用文字说明备图。

不要用纯哈希、乱码当文件名。语音和视频请不要放进本目录（引擎不会发语音/视频）。
